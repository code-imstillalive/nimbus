**Energex two-way tariff (96200 / 96200X), from 1 Nov.** It pays an export
reward of about +12.2 c/kWh 17:00-20:00 November to March, and charges about
−2.2 c/kWh 11:00-13:00 April to October.

  reward, correctly time-banded; only its `period`/`network_rate` labels are
  empty (upstream, cosmetic). Mark's read of an Amber feed-in forecast showed
  the −2.2 c drop at exactly 11:00-13:00, so an Amber install prices both
  halves already. Closed.
- A LocalVolts Flex Up forecast does not show the charge: its buy − sell gap
  holds 1.7-1.9 c from 09:00 to 15:00 with no step at 11:00 or 13:00 (table on
  #2197).
- #2197 adds an optional setting, export time-of-export adjustments, added
  only to periods priced by source 1 or the AEMO fallback, never to a tariff
  feed's or a consolidated period. Checked on devhub with production's
  96200/96200X sensors copied in and consolidation off: 203 periods, 0
  mismatches against the expected adjustment. Mark requested changes (21:04):
  if LocalVolts' API doesn't show it, LocalVolts probably doesn't pay it, and
  no 1 Nov LocalVolts forecast has been seen. Agreed, and #2197 is a draft.
  It merges only if settlement shows the credit.
