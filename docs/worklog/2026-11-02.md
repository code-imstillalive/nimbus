## Overnight: the 4-24 h blend looked worse than all its sources

At 01:55 the reference household's 4-24 h import blend scored 4.0 c against 2.2 c and 2.1 c for the two sources it weights, which a weighted mean can't do. Cause: pending forecasts recorded before #2218 (installed there at 13:14 on 1 Nov, 0.94.503 straight to 0.94.505) carry no stored offset, so `settle()` scores the sources with the offset learned by settle time (the old, flattering scoring) while the blend is scored raw. The 4-24 h bucket keeps the forecast closest to 840 min ahead, so those entries kept settling for about 14 h.

| 4-24 h, MAE | provider | retail from RRP | blend |
|---|---:|---:|---:|
| import, 01:55 | 2.2 c | 2.1 c | 4.0 c |
| import, 05:55 | 5.8 c | 5.2 c | 5.6 c |
| export, 05:55 | 5.2 c | 4.6 c | 5.1 c |

Once worked through, the blend sits just under the provider on both sides. Consequence for #1786: the week's measurement starts about 14 h after the upgrade (about 03:15, 2 Nov), not at it. Posted on #1786. A correction I made at 02:05: #2218 shipped in 0.94.504, not 0.94.505; the test box got it at 09:21 on 1 Nov.

Also seen: the day-2-to-7 source held 54 % of the 4-24 h weight on a 1.7 c score that hadn't moved for hours. It has a price at that lead only near the day boundary; once scored again its score rose to 3.1 c. Asked Mark whether a rarely scored source's weight should decay.

**Mark (06:10):** against decaying toward uniform, which would discount the source exactly when it comes back with a fresh price. His suggestion: inflate the effective MAE by time since the bucket's last sample, `mae * (1 + k * hours_since_last_sample)`, back to full confidence on the next sample. Test both on the stored history from after the settle window. Agreed; it runs with the week's blend-against-provider measurement, k at 0.01, 0.02 and 0.05 per hour. The stored history keeps each pair's interval time, so the elapsed time can be computed without new collection.

**#2189 closed (06:05):** the test install updated itself from 0.94.503 to 0.94.505 through the 2026.11 Marketplace, so `hacs.json` plus tagged releases is all an install needs. What remains is the HA MCP server's HACS tools, which aren't this repo's.
